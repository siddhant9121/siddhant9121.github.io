Projects

AML/CFT transaction flagging system

January to March 2026

Monitors transactions for money laundering and terrorism financing on IBM's synthetic dataset of more than five million transfers. A random forest with a tuned decision threshold does the flagging, using features drawn from FATF typologies: cross-currency hops, round amounts and transaction velocity. Flagged cases become suspicious transaction reports graded high, medium or low under the FATF Recommendations and the PMLA 2002, with a Plotly dashboard for compliance review.

Python, scikit-learn, pandas, SMOTE, Plotly

View code on GitHub

  • 77% recall, when only 0.1% of transactions are laundering
  • 5M+ transactions scored
  • 24,994 high-risk alerts surfaced

DAPM: asymmetric beta analytics engine

April to June 2026

An implementation of the dichotomous asset pricing model from Zou (2005). It estimates separate betas for rising and falling markets, which shows the asymmetry a single CAPM beta averages away. A screening and backtesting engine ranks stocks by that asymmetry, served through FastAPI with a PySide6 desktop client that pulls prices from yfinance.

Python, NumPy, SciPy, FastAPI, PySide6

View code on GitHub

  • 43.9% lower pricing error than classical CAPM
  • p = 0.0059 on a Wilcoxon signed-rank test across 31 stocks
  • 0.71 Sharpe ratio and 11.7% annualised return in a long-short backtest, 2021 to 2024

Reads banking and KYC documents and pulls out the fields a reviewer would otherwise type in by hand. The full machine-learning lifecycle is built around it: experiment tracking, model versioning, CI/CD, containerised deployment, and a feedback loop from human reviewers.
